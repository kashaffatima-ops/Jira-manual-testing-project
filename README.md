# Jira-Based Manual Testing & Defect Analysis Project

## Overview

This repository contains a comprehensive Software Quality Assurance (SQA) project conducted on an Event Management System. The project demonstrates manual testing practices, test case design, test execution, defect tracking, and bug analysis using Jira.

The primary objective was to evaluate the application's functionality, identify defects, analyze their impact, and provide recommendations for improving software quality and user experience.

## Project Scope

The testing activities covered the following modules:

* User Authentication (Login, Signup, Password Reset)
* Event Management
* Meeting Management
* Member Management
* User Profile Management
* Event Image Management
* Event Participation Requests
* Event Proposal Requests
* Role-Based Access Control

### Defect Analysis

The project identified and documented critical defects including:

* Invalid email validation issues
* Empty field submission vulnerabilities
* Past date acceptance issues
* Missing input validations
* Role authorization flaws
* Data integrity issues

Each defect includes:

* Description
* Expected Result
* Actual Result
* Impact Analysis
* Proposed Solution
